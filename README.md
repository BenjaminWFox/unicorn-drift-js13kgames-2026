# UniCARn

A js13kGames 2026 time trial. Drive a unicorn-with-tires around a concave rainbow
circuit, hop into a power-slide, and race the ghost of the world's best run.

```
npm i
npm run dev
```

Open http://localhost:5173/

```
npm run build    # production zip
npm run seed     # optional UNICARN-RELAY board pulser
```

See [SPEC.md](SPEC.md) and [SIZE_LOG.md](SIZE_LOG.md). The original js13k-starter
platformer is archived in `src/_demo/` and is not part of the game.
